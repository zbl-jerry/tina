# GitHub brand images

| File | Where it goes |
|---|---|
| `avatar-512.png` | GitHub profile/org avatar. A repository's icon is the owner's avatar, not a per-repository image. |
| `social-preview.png` | Repository **Settings → General → Social preview** (1280×640). |
| `../readme/tina-banner.png` | README banner already referenced at the top of the root README. |

GitHub does not expose a per-repository avatar through git or the public API.
To change the icon shown beside the repository name, update the owner's GitHub
profile picture; to change the link preview card, upload `social-preview.png`
in the repository settings.
