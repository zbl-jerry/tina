# 上游未合入 PR 需求审计（Tina，2026-11-20）

## 0. 结论摘要

- 审计对象：`vorssaint/vorssaint-utils` 全部 **583 个 open PR**（#1115–#4283），创建时间 2026-08-28 至 2026-11-20，描述正文合计约 **152 万字符**。
- 本地基线：`faada18`，与上游 `main` HEAD 完全一致（Tina 仅做了改名、CI 和文档调整）。因此“上游 main 已实现”等价于“本地已实现”。
- 逐条结果：**10 个已被上游实现（A 类过期）**，**38 个被更优/更新的 PR 取代（B 类过期）**，**18 个与 Tina 产品范围不符或无产品价值（C 类过期）**，合计 **66 个完全过期 PR**；另有 **86 个补丁整体失效**（冲突且 diff 超过 100 文件或 5000 行新增，无法直接移植，但需求可能仍有效）。
- 剩余 **431 个有效候选**，其中价值 4–5 星 **106 个**、明确建议采纳 **73 个**。本报告把它们归并为 **13 条战略需求 + 88 条增强需求**，按产品功能价值从高到低排序。
- 最大缺口集中在 13 个“付费 App 替代级”能力：Launchpad 替代、菜单栏图标管理、窗口 Zones、键盘重映射、HiDPI/分辨率管理、多输出音频、Agent 审批、听写、电池养护、窗口置顶、触控板手势、错键盘布局修复、无刘海设备也能用的 Island 页面。
- 旧 PR（8–9 月）普遍带有数百文件的异常 diff（合并基线漂移或分支污染），**不要直接 cherry-pick**；把描述当需求、按当前代码重写，成本更低。

|---|---:|

价值量表：5 = 可单独成为安装理由的核心能力，或修复严重缺陷；4 = 对核心功能的实质性增强，受众广；3 = 有用的利基/体验改进；2 = 边缘、装饰性；1 = 无产品价值。

> 方法限制：本报告基于 PR 描述与本地代码静态核对，没有逐个编译/运行 583 个补丁。5 星是产品判断，不代表技术可行性已验证；带私有 API、特权 helper、系统扩展的方案在排期前必须做技术验证。

### P0 实施建议

1. **先做“可独立发布”的 4 个**：R01、R03（先 #3274 MVP）、R12、R08（#3127 MVP）。这四项风险可控、感知强，能快速形成版本卖点。
2. **再做“平台能力” 4 个**：R02、R05、R10、R06。它们决定 Tina 能否替代 Bartender/BetterDisplay/Loop/音频工具，但都需要较长的权限与兼容性验证。
3. **最后做“高风险高回报” 5 个**：R04、R07、R09、R11、R13。统一要求：默认关闭、明确权限说明、失败可恢复、提供“安全模式”开关。
