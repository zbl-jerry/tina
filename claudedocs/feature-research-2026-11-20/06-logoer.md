# 自定义菜单栏 Apple 标志样式

> 调研日期 2026-11-20 · 上游 <https://github.com/lihaoyun6/Logoer> @ 0.2.2
> 决策：**reject** · 建议标签：`enhancement`

### 问题或动机

部分用户希望菜单栏左上角的 Apple 标志换成彩色、复古或自定义图案，用来做个性化或录屏装饰。Tina 目前只提供自己的菜单栏读数与图标，不涉及系统标志。

### 期望的解决方案

**MVP**

- 若做：提供一个菜单栏标志样式选择器，覆盖 Apple 菜单区域，可恢复默认。

**后续可选**

- 自定义图片上传、按亮/暗模式切换。

### 开源调研结论

#### 硬约束

| 约束 | 结论 | 依据 |
|---|---|---|
| macOS 15 | pass | 上游支持 macOS 11+，纯绘制；14/15 均可用 |
| 原生实现 | pass | Swift 原生，1.9 MB DMG |
| 上游 Release 体积（若有） | pass | `Logoer_v0.2.2.dmg` 1.9 MB |
| 复杂度 | conditional | 依赖菜单栏窗口几何/覆盖层实现，属于未公开的界面结构；每个 macOS 大版本都可能失效 |
| 不重复 | new | Tina 没有系统标志定制 |

#### 上游产品价值

- JTBD：把菜单栏 Apple 标志换成喜欢的样式。
- 频率与痛点：设置一次后不再碰；纯装饰，痛点低。
- 替代品：Logoer 本身、其他壁纸/主题工具。
- 可核实信号：上游最后一次发布为 2024-08，近两年无更新；这与其依赖未公开菜单栏结构、维护成本高相符。

#### Tina 用户增量收益

- 新增能力：个性化菜单栏标志。
- 协同：无；与 Tina 的菜单栏读数甚至可能争用同一区域。
- 替代：可少装 Logoer，但收益一次性。
- 代价：未公开菜单栏几何、每个系统版本都要回归测试、可能影响 Tina 自己的菜单栏项。

#### 成本、风险与 MVP

- 规模：S（技术上），但维护是长期成本
- Tina 增量体积：约 0.1 MB + 若干图片资源
- 主要风险：未公开 UI 结构、系统升级即失效、与菜单栏读数冲突
- MVP 边界：不推荐进入 MVP
- 决策：**reject**——用户价值低于 3（纯一次性装饰），而依赖未公开菜单栏结构、需要长期跟随系统版本维护，不符合 Tina 的收益/成本比

#### 评分

| 维度 | 分数（1–5） | 理由 |
|---|---:|---|
| 上游产品价值 | 3 | 有趣但低频的装饰性需求 |
| Tina 用户收益 | 2 | 边际改进 |
| 契合度 | 2 | 不与其他功能协同，还可能冲突 |
| 实现成本（反向） | 4 | 代码量小 |
| 风险（反向） | 2 | 未公开结构，随系统更新失效 |
