## 从源码构建

构建好的发布包见 [Releases 页面](https://github.com/zbl-jerry/tina/releases)。要使用 Xcode Command Line Tools 在本地构建：

```sh
git clone https://github.com/zbl-jerry/tina.git
cd tina
./build.sh --dev            # 构建独立的开发版
./build.sh --dev --install  # 安装并启动它
```

直接运行 `./build.sh` 构建的是优化版。目录结构、测试和约定见[贡献指南](CONTRIBUTING.md)。

## Tina 是怎么开发的

Tina 主要采用 **AI 辅助的 vibe-coding** 方式开发：功能、修复和测试常常由编码智能体在维护者身边提出并实现。欢迎编码智能体提交 issue、补丁和 pull request。

智能体的贡献和其他改动遵循同样的门槛：范围聚焦、运行相关的构建和测试、如实说明实际验证了什么，并在权限、隐私、破坏性文件操作和私有 API 方面留出一轮人工审查。未经审查的智能体产出不会被合并。

## 只安装你用到的功能

可以逐个挑选功能，也可以从预设方案起步。卸载的功能会停止加载并从界面消失；重新安装即可恢复原有设置。安装引导只申请你的选择所需的权限。

## 它的全部能力

### 声音

- **音量混音器。** 按应用设置音量，把偏小的音频提升到 100% 以上，并可固定或重排常用应用。不需要音频驱动。
- **按应用分配输出。** 音乐走音箱，通话走耳麦，互不干扰。
- **输出设备切换。** 用快捷键切换音频输出，并在耳机断开时自动降低音量。
- **麦克风工具。** 选择首选的输入设备，在支持的设备上调节电平，并用一个快捷键使用可用的麦克风静音或输入音量控制。Siri 和部分应用仍可能听到你；麦克风静音不是隐私锁，它的指示灯只表示功能已开启，不表示所有应用都收不到声音。
- **音乐应用启动拦截。** 在检测到播放键被按下后，阻止 Music 被意外启动。需要辅助功能权限。

### 了解你的 Mac 在做什么

- **系统监视器。** CPU、GPU、内存、温度、电池健康度和功耗，带历史曲线，并列出耗电大户。
- **风扇控制（测试版）。** 设置手动转速或温度曲线，并实时查看 RPM。
- **菜单栏读数。** 把自选的读数、占用率条形、电池剩余时间或风扇转速直接放进菜单栏。
- **网络。** 查看实时流量、本次会话总量和本机 IP 地址，或运行速度测试。
- **提醒。** 在 CPU 持续高负载、温度过高、内存压力大、磁盘空间不足或电量偏低时收到通知。

### 窗口与 Dock

- **应用切换器。** 通过实时预览、搜索和显示器筛选在应用与窗口之间切换。更简单的模式无需屏幕捕捉即可使用。
- **启动台。** 全屏应用网格，支持文件夹、搜索、分页和拖动排序，可从快捷键、灵动岛或可选的 Dock 图标打开。
- **窗口布局。** 把窗口吸附到布局中、在显示器之间移动，并通过快捷键、屏幕边缘或按住修饰键拖动的手势恢复先前位置。自定义贴靠区（需主动开启）在按住 Option 时显示；把窗口拖入贴靠区并松开即可调整大小，窗口布局设置中可为每台已连接的显示器提供独立的可编辑区域。
- **窗口置顶。** 把任意窗口以实时镜像固定在其他应用之上，镜像可移动和缩放，源窗口隐藏或被遮挡时暂停，点击镜像即可把操作交还给真实窗口。参见[窗口置顶](docs/WINDOW-PINNING.md)。
- **窗口平铺。** 用一个快捷键把某个显示器上的所有窗口排成网格、行或列，再次按下可循环切换不同布局。该功能会遵循间距、菜单栏与 Dock 预留区域以及被忽略的应用。参见[多窗口平铺](docs/TILE-WINDOWS.md)。
- **Dock 预览。** 悬停 Dock 图标即可预览各桌面上的窗口，并能在预览中切换、关闭、移动或吸附它们。
- **Dock 点击。** 点击已激活应用的 Dock 图标，可将其最小化、隐藏或在窗口间循环。
- **窗口最大化。** 用绿色按钮铺满屏幕，而不会新建一个空间。
- **固定空间顺序。** 让空间保持你设定的顺序，而不是按最近使用重新排列。关闭后会恢复你之前的设置。
- **关闭即退出。** 当选定应用的最后一个窗口关闭时退出该应用。
- **退出与关闭保护。** 按应用防止误按 ⌘Q 或 ⌘W，可选择长按、双击或额外修饰键确认。

### 键盘与鼠标

- **文本片段。** 用短触发词展开为文本，支持剪贴板、日期和时间变量，也可从可搜索菜单中插入片段。
- **平滑滚动。** 让滚轮拥有流畅的滑动感，速度和响应可调。支持按应用覆盖设置，并可在按住某个键时保留原始滚轮，便于精确操作的应用无需改动全局设置。参见[按应用滚动](docs/PER-APP-SCROLL.md)。
- **指针加速。** 关闭鼠标加速，关闭该功能时恢复你之前的设置。
- **线性滚动。** 无论滚轮转得多快，每一格都滚动相同的行数。
- **焦点跟随鼠标。** 经过一段可调的停顿后，把指针下的窗口带到最前。
- **滚动方向。** 独立于触控板反转鼠标的垂直和水平滚动方向。
- **按住按键横向滚动。** 按住指定按键时，把滚轮的垂直滚动转换为水平滚动。
- **侧键。** 在 Finder、浏览器和兼容应用中使用鼠标的后退和前进键。
- **鼠标按键快捷键。** 为额外按键和侧向滚轮分配按键，或使用按键拖动手势触发空间和调度中心。
- **中键点击。** 把三指按压触控板变为中键点击。
- **不受影响的应用。** 把指定应用排除在鼠标增强之外。
- **多余点击过滤。** 忽略磨损鼠标按键产生的意外连击，且不会延迟正常点击。
- **按键防抖。** 过滤老化键盘产生的重复字母。
- **Super 键。** 把 Caps Lock 或右侧修饰键当作快捷键组合使用，并支持独立的轻按操作和应用排除。
- **输入法布局修正。** 用错键盘布局打字后，轻按右 Option 键即可用另一个已启用的布局重打上一个词。
- **自动输入源。** 为每个应用指定输入源：启动后首次激活时切换，之后每次返回时也切换。支持全局默认、永不切换列表，以及供 dotfiles 使用的 JSON 规则文件。切换发生在应用进入前台之后，绝不在打字过程中，且不需要任何权限。参见[自动输入源](docs/AUTO-INPUT-SOURCE.md)。
- **键盘快捷键。** 在一处管理各项功能的快捷键，并可在功能启用时选择接管受支持的 macOS 快捷键。

### 剪贴板、文件与链接

- **剪贴板历史。** 搜索本地的文本、图像和文件历史，固定常用条目，预览内容并用快捷键粘贴。可预览复制的文件、把条目拖进其他应用、排队连续粘贴，并从条目菜单转换文本大小写。
- **自动清空剪贴板。** 在延时后、睡眠或锁屏时清空系统剪贴板，同时保留已保存的历史。
- **粘贴为纯文本。** 去除格式后粘贴，同时保留剪贴板原有内容。
- **置物架。** 在拖动时把文件、文本和链接暂存在指针附近，之后再放入目标位置或分享出去。
- **Finder 快捷键。** 用 ⌘X 和 ⌘V 移动文件，用 F2 重命名，或把复制的图像粘贴为 PNG 文件。
- **清理链接。** 手动或自动移除链接中的跟踪参数。
- **磁盘映像安装器。** 从挂载的磁盘映像安装应用并推出映像，可选清理下载文件。在某个文件夹中放入空的 `.tina-no-install` 文件，即可让该文件夹及其子文件夹里的映像跳过提示；删除该文件后恢复提示。隐藏的挂载点和位于系统临时目录的映像始终跳过。其他可见挂载点仍可能弹出提示，包括未标记文件夹中的脚本挂载。对于 Downloads 之外未加标记的映像，移到废纸篓需要为当次安装选择该选项。

### 日常工具

- **灵动岛。** 把音乐、通知、日历、计时器、下载和常用控制常驻在摄像头开孔周围，在其他 Mac 上则使用模拟开孔。可自定义分区和快捷键，可选歌词、实时频谱、摄像头预览和文件工具。
- **AI 智能体。** 在灵动岛中跟踪 Claude、Codex、OpenCode 和 GitHub Copilot：计划限额及其重置时间（在可获取时）、token、API 价值、模型、项目和实时工作状态，长时间任务完成时会给出提示。也可以在那里使用 Codex 的留存重置额度，每个额外的 Codex 账号（`CODEX_HOME`）都可以有自己的限额卡片。Copilot 使用本地 CLI／应用会话日志；其 token 总量在关机指标到达时更新，汇总的 API 价值按基础费率估算。
- **命令栏。** 在一个输入框里搜索应用、窗口、文件、剪贴板历史、文本片段和应用菜单命令。还能计算、换算单位、查找 emoji 或运行已保存的脚本。
- **快捷面板。** 用 ⌃⌘V 打开常用工具的浮动面板。
- **快捷开关。** 切换外观、隐藏桌面图标、推出磁盘、清空废纸篓、锁定屏幕等。
- **退出应用。** 在一个列表中查看所有已打开的应用，可逐个退出、全部退出，或只保留最前面的那一个。
- **环形菜单。** 在指针周围打开可自定义的应用、文件、快捷键和工具转盘，支持配置文件和子菜单。
- **便签。** 在标签页中保存自动保存的笔记，支持 Markdown 预览和导出，可放在浮动窗口或灵动岛中。
- **清洁模式。** 清洁时锁定键盘输入，可显示黑屏或一个小型可见提示。
- **验证码。** 从菜单栏生成标准 TOTP 验证码，无需账号或同步服务。验证码在悬停前保持隐藏，密钥只存在本机钥匙串中，并可通过 otpauth 设置链接、Base32 密钥或屏幕上的二维码添加账号。参见[验证码](docs/TOTP-AUTHENTICATOR.md)。

### 捕捉与创作

- **屏幕捕捉。** 在同一个选择器中切换截图、录屏、文字识别和取色，并带有像素放大镜。
- **截图。** 捕捉区域、窗口、整个屏幕或滚动页面。可标注、裁剪、打码、添加背景和水印，也可固定截图或通过共享菜单发送。
- **录屏。** 分别录制系统音频和麦克风轨道，可选带可拖动的摄像头气泡。可把按下的按键显示为可选叠加层，支持剪辑、删除片段、自动缩放、模糊隐私内容，并导出为视频或 GIF。
- **摄像头预览。** 通话前在浮动镜像窗口或灵动岛中检查摄像头。
- **从屏幕复制文字。** 离线识别任意屏幕区域的文字，或读取二维码。
- **取色器。** 把屏幕颜色复制为 HEX、RGB、HSL 或 SwiftUI 代码。
- **媒体工具。** 压缩和编辑视频、批量转换图像、添加水印、制作 GIF、提取文本，全部在本地完成。

### 应用管理

- **应用更新。** 在一个列表中检查商店应用、包管理器应用和受支持的开发者源。可批量安装受管理的更新，或打开应用自带的更新程序。
- **清理器。** 手动或按计划移除缓存、日志和应用遗留文件。
- **通讯应用下载。** 按保留规则查看、整理通讯应用中的下载文件，或将其移到废纸篓。
- **卸载器。** 卸载应用，并在把相关缓存、偏好设置和辅助程序移入废纸篓前先行审查。
- **Homebrew 管理。** 不打开终端即可搜索、安装和移除 formula 与 cask。
- **端口管理。** 找到监听网络端口的进程，并在安装了 Kill Process 时停止它们。
- **hosts 配置。** 保存多套命名的 hosts 配置，启用其中一套并通过一次管理员授权应用到 `/etc/hosts`。每次应用前都会先备份当前文件，只替换 Tina 标记的段落，且任意备份都可恢复。参见[hosts 配置](docs/HOSTS-PROFILES.md)。

### 能耗与显示器

- **保持唤醒。** 让 Mac 按计时器保持工作、合盖时保持工作，或在指定应用、电源、外接显示器存在时保持工作。
- **显示器。** 单独控制每台显示器和亮度：在支持时使用硬件控制，亮度键支持半格或四分之一格调节，可选在显示器最低亮度之下进一步调暗，并以软件调光作为回退方案，还可调节显示器内置扬声器的音量和静音。显示器预设会保存每台显示器的分辨率、亮度、扬声器音量以及主显示器，然后可从面板、全局快捷键，或在指定显示器连接／断开时恢复该组合。
- **额外亮度。** 利用 MacBook Pro XDR 显示器的 HDR 余量，突破正常最高亮度。
- **夜间护眼暖色。** 日落后让所有显示器变暖，早晨恢复日间色彩。可选睡前色温、预设、暂停到日出，以及「更暖」或「更冷」的微调。仅使用 gamma 表，不申请任何权限，关闭时恢复原始色彩。
- **睡眠时关闭蓝牙。** 睡眠期间断开蓝牙，唤醒时仅在 Tina 将其关闭的情况下恢复。
- **充电上限（测试版）。** 让插着电源的 MacBook 保持在指定电量，恢复充电时略低于目标以避免反复切换，并可在需要时一次性充满。使用 Tina 现有的特权辅助程序，关闭该功能或退出 Tina 时恢复正常充电。参见[充电上限](docs/CHARGE-LIMIT.md)。

## 默认私密

Tina 以本地为先，没有账号、分析统计或跟踪。网络只被你可见的功能触碰：检查更新、速度测试、Homebrew 操作和可选的在线歌词查询。完整说明见[隐私说明](docs/PRIVACY.md)。

Tina 不运营任何托管式的截图／录屏分享或反馈后端。本地的捕捉、编辑和导出工具都能正常使用；带过期链接的上传按钮会提示服务不可用。

权限也是同样的态度。每一项权限都是可选的，应用会用直白的语言解释它，显示哪些功能实际在用它，甚至会在你授予的某项权限已不再被任何功能需要时提醒你，并提供撤销的快捷入口。

## 卸载

要彻底移除 Tina（包括它的设置和权限）：

```sh
./Tools/uninstall.sh
```

## 开发

`main` 镜像上游项目，仅用于同步上游改动。所有开发都在 `dev` 上进行，它是仓库的默认分支。

## 出问题时

启动问题、权限问题和预览缺失见[故障排查](docs/TROUBLESHOOTING.md)，需要帮助见[支持](SUPPORT.md)。
